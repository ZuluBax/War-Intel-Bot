HOW TO ADD THE WAR INTEL BOT TO YOUR DISCORD SERVER
===================================================

Easy steps. Do them in order. Takes about 10 minutes.


WHAT YOU NEED FIRST
-------------------
- You must be a boss of the Discord server (you have "Manage Server").
- Your Torn faction ID (a number).
- A Torn API key. It's like a password the bot uses to read Torn.


STEP 1: INVITE THE BOT
----------------------
1. Click this link:
   https://discord.com/api/oauth2/authorize?client_id=<BOT_CLIENT_ID>&permissions=117776&scope=bot%20applications.commands
2. Pick your server from the list.
3. Click Continue.
4. Leave every box ticked.
5. Click Authorize.
   Now the bot is in your server, with its own role called "War Intel Bot".


STEP 2: FIND YOUR FACTION ID
----------------------------
1. In Torn, open your faction's page.
2. Look at the web address at the top.
3. The number after "ID=" is your faction ID. Write it down.


STEP 3: MAKE A TORN API KEY
---------------------------
1. In Torn, go to Preferences, then API Keys.
2. Make a new key and set it to Limited Access.
3. Copy it. Keep it secret, like a password.
   Don't paste it in a normal chat.


STEP 4: TELL THE BOT WHO YOU ARE
--------------------------------
Type these in any channel. Only you see the bot's replies, so your key stays safe.

1. Type /setup faction, then your faction ID, then press Enter.
2. Type /setup torn-key, then paste your key, then press Enter.
   - "Torn key saved" means it worked.
   - "Torn key rejected" means the key is wrong. Make a new one and try again.
3. (Optional) Type /setup ffscouter-key, then paste an FFScouter key if you
   have one. It helps the bot guess how strong enemies are.
4. Type /setup show. It shows what you saved (keys hidden).
   Check that it looks right.


STEP 5: WAIT FOR A WAR
----------------------
- Nothing appears yet. That's normal.
- When Torn announces your next ranked war, the bot wakes up by itself
  within 1 minute.
- It makes a group called "WAR - (enemy name)" with 5 channels inside:
    war information
    enemy stats
    target board
    war log
    enemy activity
- It keeps filling them in by itself during the war.


STEP 6 (OPTIONAL): MAKE THE WAR CHANNELS READ-ONLY
--------------------------------------------------
This lets people read the war channels but stops them typing in them.
You only do it once. The bot uses the same channels for every war after.

1. Right-click the "WAR" group name, then click Edit Category.
2. Click Permissions.
3. Click @everyone.
4. Set Send Messages to the red X.
5. Click Save Changes.


ANOTHER WAY: MAKE THE CHANNELS YOURSELF (BOT NEEDS NO "MANAGE CHANNELS")
-----------------------------------------------------------------------
Use this if you don't want the bot to be able to make or change channels.
You make the 5 channels, and the bot only posts in them.

1. Invite the bot with THIS link instead of the Step 1 link:
   https://discord.com/api/oauth2/authorize?client_id=<BOT_CLIENT_ID>&permissions=117760&scope=bot%20applications.commands
   Bot already in your server? Go to Server Settings > Roles > War Intel Bot
   and switch Manage Channels off. That's all.
2. Make 5 text channels, named:
   war-information, enemy-stats, target-board, war-log, enemy-activity
3. In each channel, let the "War Intel Bot" role in: View Channel, Send Messages,
   Embed Links, Read Message History (and Attach Files in war-log for the
   end-of-war spreadsheet).
4. Go into each channel and type /setup board, then press Enter.
   The bot works out which board goes there from the channel's name.
   Different name? Pick the board in the "board" box.
   It tells you which boards still need a channel.
5. Type /setup show to check all 5 are set.

The same channels are used for every war. To stop a board posting somewhere,
run /setup board in that channel with "remove" set to True.


WARNING: DON'T USE /setup channel (UNLESS YOU KNOW WHY)
-------------------------------------------------------
It puts everything into one channel instead of 5 channels, which gets messy.

If you really want it, you must let the bot into that channel first:
1. Open the channel's settings (gear icon), then click Permissions.
2. Click + and add the "War Intel Bot" role.
3. Give it a green tick for: View Channel, Send Messages, Embed Links,
   Read Message History. Then save.

To go back to 5 channels: type /setup channel with the box left empty.


SOMETHING WRONG?
----------------
- No /setup commands when you type / ?
    Kick the bot and invite it again with the Step 1 link.

- The bot says "You do not have permission to use that command." ?
    You need "Manage Server". Ask a server boss to do the setup.

- No war channels yet?
    Is a war announced? If not, it's normal. Wait.

- Channels are there but empty?
    The bot is probably blocked from those channels.
    See the WARNING section above.

- Want to turn the bot off?
    Type /setup disable.
